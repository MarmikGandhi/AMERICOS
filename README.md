# Americos — Frontend Internship Trial Project

## Project Overview

This project was developed as part of a **3-day frontend internship trial period at Americos**.

The objective was to transform the provided design and requirements into a **modern, responsive, and interactive frontend website**, focusing on clean UI implementation, navigation, responsiveness, and user experience.

## Objectives

* Convert the provided design into a functional website.
* Build a clean and modern frontend interface.
* Implement responsive layouts for different screen sizes.
* Create reusable and organized frontend components.
* Implement functional navigation between sections/pages.
* Maintain consistent styling, spacing, typography, and visual hierarchy.
* Ensure interactive elements and navigation states work correctly.

## Key Features

* Responsive website layout
* Modern UI/UX implementation
* Interactive navigation bar
* Active navigation states
* Multiple website sections/pages
* Responsive design for desktop and mobile screens
* Structured and maintainable frontend code
* Image and visual asset integration
* Smooth user experience and section navigation

## Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layouts, responsiveness, and animations
* **JavaScript** — Interactivity and dynamic behavior
* **Git & GitHub** — Version control and project management

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MarmikGandhi/AMERICOS.git
```

### 2. Navigate to the Project

```bash
cd AMERICOS
```

### 3. Run the Website

Open `index.html` directly in your browser, or use **Live Server** in Visual Studio Code.

## Development Process

During the 3-day trial period, the project focused on:

### Day 1 — Initial Development

* Studied the provided design and requirements.
* Set up the project structure.
* Implemented the main website layout.
* Added navigation and major sections.
* Integrated the provided visual assets.

### Day 2 — UI Development & Refinement

* Improved page layouts and styling.
* Implemented responsive behavior.
* Added interactive navigation states.
* Organized CSS and JavaScript.
* Refined spacing, typography, and visual consistency.

### Day 3 — Final Improvements

* Fixed UI and navigation issues.
* Improved responsiveness.
* Tested different sections and interactions.
* Cleaned up the frontend structure.
* Performed final visual and functional checks.
* Prepared the project for submission.
